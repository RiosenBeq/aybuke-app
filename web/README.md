# Website (legacy copy)

The live site is **https://aybuke.org**, built from the separate repository `RiosenBeq/aybuke` and deployed by Vercel from its `main` branch. Edit the site there.

This folder is an older copy: a landing page (`index.html`), the legal pages (`legal/`, generated by `scripts/build-legal.py` from this repository's `legal/`), `app-ads.txt` and assets. `.github/workflows/website.yml` still publishes it to GitHub Pages (`https://riosenbeq.github.io/aybuke-app/`) when `web/` or `legal/` changes, so it works as a fallback for the legal pages. The app links to aybuke.org (`websiteURL`, `privacyPolicyURL` and `termsURL` in `ios/App/Resources/AppConfig.json`).

When the legal texts change: edit `legal/` here, run `python3 scripts/build-legal.py`, then copy `legal/en/*.md` and `legal/tr/*.md` into `RiosenBeq/aybuke` and run its `python3 scripts/build.py`.

Once aybuke.org is confirmed in a browser, the owner can switch this copy off (disable the Website workflow and GitHub Pages).
