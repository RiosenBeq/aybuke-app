# Website (legacy copy)

The live site is **https://aybuke.org**, built from the separate repository `RiosenBeq/aybuke` and deployed by Vercel from its `main` branch. Edit the site there.

This folder is an older copy: `index.html`, which forwards to aybuke.org, the legal pages (`legal/`, generated by `scripts/build-legal.py` from this repository's `legal/`; each names its aybuke.org page as canonical and is marked noindex), `app-ads.txt` and assets (`og-image.png` and `screens/` are no longer shown by any page here, but `scripts/marketing-images.py` still writes them). `.github/workflows/website.yml` still publishes it to GitHub Pages (`https://riosenbeq.github.io/aybuke-app/`) when `web/` or `legal/` changes, so it works as a fallback for the legal pages. The app links to aybuke.org (`websiteURL`, `privacyPolicyURL` and `termsURL` in `ios/App/Resources/AppConfig.json`).

When the legal texts change: edit `legal/` here, run `python3 scripts/build-legal.py`, then copy `legal/en/*.md` and `legal/tr/*.md` into `RiosenBeq/aybuke` and run its `python3 scripts/build.py`.

Once aybuke.org is confirmed in a browser, the owner can switch this copy off (disable the Website workflow and GitHub Pages).

## Türkçe

Yayındaki site **https://aybuke.org**; kaynağı ayrı depo `RiosenBeq/aybuke`, Vercel `main` dalından yayınlar. Siteyi orada düzenleyin. Bu klasör eski bir kopyadır; GitHub Pages'te yedek olarak yayınlanır. `index.html` ziyaretçiyi aybuke.org'a yönlendirir, hukuk sayfaları aybuke.org'daki karşılıklarını kanonik adres olarak gösterir ve arama motorlarına kapalıdır (noindex). Hukuk metinleri değişince bu depoda `legal/` düzenlenir, `python3 scripts/build-legal.py` çalıştırılır ve metinler web sitesi deposuna kopyalanır.
