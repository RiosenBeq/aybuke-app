# Website

A static landing page for Glowlit (`index.html`), the legal pages (`legal/`, generated by `scripts/build-legal.py`) and assets (`assets/`, partly generated by `scripts/marketing-images.py`). No build step, no trackers.

## Publish with GitHub Pages (free)

1. Repository **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. **Actions → Website → Run workflow** (`.github/workflows/website.yml`). The site appears at `https://<user>.github.io/<repo>/`.
3. Optional: add a custom domain such as `glowlit.app` under Settings → Pages, then set in `ios/App/Resources/AppConfig.json`:
   - `websiteURL`: `https://glowlit.app` (share captions link here until the App Store page exists)
   - `privacyPolicyURL`: `https://glowlit.app/legal/en/privacy-policy.html`
   - `termsURL`: `https://glowlit.app/legal/en/terms-of-use.html`

Before launch, replace the "Coming soon to the App Store" button with the official [App Store badge](https://developer.apple.com/app-store/marketing/guidelines/) and the app's link, and uncomment the `apple-itunes-app` meta tag.

## Türkçe

GitHub'da **Settings → Pages → Source: GitHub Actions** seçeneğini açın, ardından **Actions → Website → Run workflow** ile siteyi yayınlayın. Kendi alan adınızı (`glowlit.app`) bağladıktan sonra `AppConfig.json` dosyasındaki `websiteURL`, `privacyPolicyURL` ve `termsURL` alanlarını yeni adreslerle güncelleyin.
